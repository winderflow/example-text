# RCSB / PDB-101 高清科研插图来源核验

核验日期：2026-11-03。本页只记录来源、授权核验边界及后续下载方式，**不表示已经从 RCSB 官网下载图片**。

## 目标素材与来源

- [RCSB PDB](https://www.rcsb.org/)：蛋白质和其他生物大分子的结构数据库。
- [PDB-101](https://pdb101.rcsb.org/)：RCSB 的教育门户；重点寻找 Molecule of the Month 等作品中的分子插图、海报和可用于科学交流的原图。
- `cdn.rcsb.org`：可能由官方作品页引用的图像分发主机。下载时必须使用真实作品页实际给出的文件链接，不根据名称猜测文件路径。

优先选择具有明确图片使用条款、作者署名和原图下载链接的作品；有条件时保留 SVG、透明背景 PNG 或高分辨率原始位图。一个作品中的小预览图和高清版本不应当作两件独立作品重复计数。

## 当前核验结果

当前云环境对 `www.rcsb.org`、`pdb101.rcsb.org`、`cdn.rcsb.org` 的请求在连接阶段返回代理 `403 Forbidden`。这是本次执行环境的访问限制，不能据此判断 RCSB 网站故障或原图不存在。

官方 [RCSB GitHub 组织](https://github.com/rcsb) 可访问。已检查其公开仓库目录，未找到可以直接替代 PDB-101 官网、同时保留逐图许可的 Molecule of the Month 原图合集。

另外检查了官方 [rcsb-training-resources](https://github.com/rcsb/rcsb-training-resources) 和 [rcsb-documentation](https://github.com/rcsb/rcsb-documentation)。前者 README 将培训材料描述为 open source，但这不能单独确定所含第三方图片的具体许可和署名；后者是文档网站的软件模块，软件许可不自动赋予外部引用图片的使用权。本轮没有拿网站截图、软件代码或练习数据冒充已下载的 RCSB 高清插图库。

## 逐图授权与引用

结构坐标、实验数据、网站软件、文章正文、插画和摄影作品可能适用不同条款。尤其不能将 PDB 数据的开放条件直接套到教育插图，或未经核验就把整站图片统一标为 CC0、CC BY 或其他许可。

后续收集每件图像时，须一并保存：

1. 实际作品名称及原始网页地址。
2. 图像创作者，以及原页要求保留的机构或版权信息。
3. 覆盖该图片的具体许可名称、版本、链接及核验依据。
4. 真实原图链接、像素尺寸或 SVG 的 `viewBox`、原始文件大小及 SHA-256。
5. 是否修改。原图直接镜像时注明未修改；另行处理背景、裁剪或配色时分别保留原图并说明变化。

如果通过 Wikimedia Commons 获得同一作品，也应读取该文件页的实际作者、来源与许可，并记录回到 RCSB / PDB-101 的来源链；不能仅凭图片标题或作者知名度推断许可。

## 访问恢复后的收集步骤

首先重新检查官方页面的当前使用条款及单件作品声明，再从真实索引和作品页中解析图像、附件与原图链接。优先采用官方现成的批量下载或公开接口；没有明确批量方式时，按站点规则以适度速率下载所选作品。

使用原图文件，不通过放大小缩略图声称获得高清图。下载后验证实际格式、尺寸、可解码性、文件哈希与对应授权记录，再加入图库检索清单。无法确认图片授权或作者链条的记录保留为候选链接，不计入已下载数量。

PowerPoint 中，支持 SVG 的版本可直接插入 SVG 并保持缩放清晰；高清 PNG 适合保留复杂分子插图的细节。选择素材时应按幻灯片上的实际显示尺寸判断清晰度，并在图注或随附署名页保留该作品要求的引用。
