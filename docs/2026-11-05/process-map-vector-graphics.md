# Process Map 科研工作流符号：新增51张

[返回本批用途分类](../MORE-OPEN-ART-2026-11-05.md)

本来源新增SVG 51张、原生高清 0张、原生标准 0张。用于科研流程绘图的彩色BPMN、DFD和UML独立SVG符号。

固定版本：[e30c9f919d93fe099c49ee15c0b97b1647a84711](https://github.com/PEC-Development-Team/Process-Map-Vector-Graphics/tree/e30c9f919d93fe099c49ee15c0b97b1647a84711)。许可概览：MIT；使用时请保留逐图作者、原作品链接和具体许可。

标准尺寸位图适合PPT中的小幅示意图，放大前请核对实际宽高；SVG可按需要放大。完整署名保存在[全库清单](../../data/manifest.csv)。
