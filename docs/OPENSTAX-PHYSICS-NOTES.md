# OpenStax 物理插图库来源核验

当前批量选择共 **1,260 张物理原图**：大学基础物理 **761 张**、大学物理 **499 张**。本批次新增 **1,256 张原生标准分辨率图**，保留此前 **4 张原生高清图**。原件长边至少 600 px、短边至少 200 px；长边 600–1599 px 标记 `native-standard`，长边至少 1600 px 标记 `native-highres`，没有上采样。分类覆盖力学、流体、热学、电磁、电路、声学、光学、量子与核物理等。
